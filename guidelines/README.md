# Annotation guidelines

| Version | Status | File |
| --- | --- | --- |
| v0 | Draft for the pilot (20 videos) | `v0.md` |

Rules for changing the guidelines:
- Never edit a version that has been used to annotate data. Copy it to the next version and record the change in its change log.
- Every annotation records `guideline_version`, so labels can be traced to the rules used.
- The Guidelines & quality track owns this folder; changes go through a pull request.
