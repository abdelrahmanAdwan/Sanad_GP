## Proposal
GitHub Flow on one private repository: one issue per task, a short-lived branch per issue, small pull requests reviewed by the folder's owner (CODEOWNERS), squash merge, no direct pushes or force pushes to `main`. Details: `CONTRIBUTING.md`.
