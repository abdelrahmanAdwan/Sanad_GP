## Decision
Work through the five health topics **sequentially**: finish one topic completely (collect, transcribe, annotate) before starting the next. Expand if time remains; otherwise submit with the completed topics. Submitting fewer than 400 videos is acceptable.

## Consequences
- Proposal Table 3 (five topics, 80 videos each) becomes a target, not a requirement.
- Each topic gets its own train/dev/test split, frozen when the topic is complete, so adding a topic never changes earlier test sets.
- The pilot should still include a few videos from other topics so the guidelines work across topics.
